## Cosmic UI Redesign
- Experience a completely refreshed interface with night-sky constellations, subtle star brightness effects, and a polished chat layout that feels natural and inviting.
- Enjoy redesigned suggestion chips and an improved sidebar history with date separators, making it effortless to find and revisit past conversations.
- Discover visual polish throughout: wider user messages, aligned text, refined header icons, and smoother scrolling that adapts to your zoom level.

## Powerful New Features
- Explore the new Metrics Dashboard with interactive charts showing your usage patterns and system performance at a glance.
- Save any conversation as a beautifully formatted PDF with markdown layout, perfect for sharing or keeping personal records.
- Build a company knowledge base that helps the AI understand your organization's unique context and provide more relevant answers.
- Adjust message streaming speed with a dedicated slider, controlling how fast responses appear on screen.

## Streamlined Authentication
- Log in securely with Microsoft 365 Single Sign-On, eliminating the need to remember separate passwords.
- Benefit from enhanced security with encrypted tokens and optimized session management.
- Enjoy a simpler, faster login flow that gets you to your conversations in seconds.

## Smarter AI Interactions
- Watch chat titles generate automatically from your first message, keeping your history organized without manual effort.
- See exactly how much context the AI is using with a dedicated indicator, giving you transparency into how your messages are processed.
- Benefit from improved web search with better link scoring and refined result presentation.
- Expand scenario prompts with an enhanced UI pinned above the composer for quick access to guided interactions.

## Polished Experience
- Cancel streaming responses instantly, with the cancellation now properly stopping the model mid-generation.
- See toast notifications when errors occur, keeping you informed without confusion.
- Enjoy reliable autoscrolling that keeps new messages in view, even on new chats.
- Experience faster, more stable performance with optimized components and reduced memory usage.
